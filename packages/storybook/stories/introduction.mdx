# DX Design System

3 패키지 구조, 3 프레임워크 지원 (React / Thymeleaf / HTML).

## 구조
- `@dx/styles` — Tailwind v4 theme + semantic 토큰
- `@dx/ui` — shadcn/ui React 컴포넌트
- `@dx/elements` — Light DOM Web Components (Thymeleaf/HTML 전용)

## 사용
React 프로젝트: `import { Button } from '@dx/ui'` + Tailwind 빌드.
Thymeleaf/HTML: `<script src=".../dx-elements.js">` + `<ds-button class="...">`.
